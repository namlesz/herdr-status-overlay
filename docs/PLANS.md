# Plany

- [ ] **Zadania Pi w tle.** Dodać osobną, dyskretną animację odtwarzaną w tle overlayu, gdy trwa co najmniej jedno zadanie Pi. Ma działać także wtedy, gdy sama sesja Pi jest bezczynna, i ustępować po zakończeniu ostatniego zadania. Zachować osobny licznik z ikoną zegara oraz widoczność ważniejszych sygnałów, takich jak blokada.
